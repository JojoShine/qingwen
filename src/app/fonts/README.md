# Geist Sans

Unmodified variable font from [vercel/geist-font](https://github.com/vercel/geist-font/tree/e1f671c727f6de7e97c1e1d26dbb44f349c19459).

Source: `fonts/Geist/webfonts/Geist[wght].woff2`. Distributed under the SIL Open Font License in [OFL.txt](OFL.txt). Self-hosted to avoid third-party font requests at runtime or build time. Chinese text uses the system Chinese sans-serif fallback.
